# Site Oficial Yago — Project Brief

## Objetivo do projeto

Este é o site profissional de Yago Rafael.

O site deve funcionar como uma vitrine comercial dos serviços oferecidos e como demonstração real da qualidade do trabalho que está sendo desenvolvido.

O principal objetivo é fazer potenciais clientes entenderem rapidamente:

- quem é Yago;
- o que ele faz;
- quais problemas consegue ajudar a resolver;
- quais serviços oferece atualmente;
- quais projetos reais já desenvolveu;
- como entrar em contato.

O objetivo final é aumentar as chances de contato e geração de oportunidades comerciais.

## Contexto profissional

Yago está estudando desenvolvimento Full Stack e atualmente possui conhecimento em:

- HTML;
- CSS;
- Git;
- GitHub;
- fundamentos iniciais de JavaScript.

JavaScript ainda está em evolução.

Futuramente pretende estudar e trabalhar também com:

- backend;
- banco de dados;
- React e outras tecnologias quando fizerem sentido;
- integrações;
- automações;
- agentes de IA;
- soluções utilizando inteligência artificial.

O site não deve fingir experiência, domínio técnico ou estrutura empresarial que ainda não existem.

## Serviços atuais

O foco comercial atual é:

- landing pages;
- sites institucionais;
- presença digital para pequenos negócios;
- desenvolvimento web personalizado dentro das capacidades atuais.

## Expansão futura

A marca deve ser estruturada para permitir crescimento futuro para serviços como:

- automações;
- integrações;
- agentes de IA;
- sistemas;
- aplicações com backend;
- banco de dados;
- soluções digitais mais complexas.

Esses serviços futuros não devem ser apresentados como experiência comprovada ou oferta consolidada antes de realmente estarem disponíveis.

## Público principal

A primeira versão do site deve conversar principalmente com:

- pequenos negócios;
- profissionais autônomos;
- prestadores de serviços;
- negócios locais;
- micro e pequenas empresas;
- pessoas que dependem principalmente de Instagram e WhatsApp e precisam melhorar sua presença digital.

A comunicação deve ser compreensível para pessoas que não possuem conhecimento técnico.

## Posicionamento

A marca deve transmitir:

- profissionalismo;
- tecnologia;
- criatividade;
- confiança;
- modernidade;
- qualidade;
- atenção aos detalhes.

O posicionamento não deve parecer:

- grande agência fictícia;
- iniciante inseguro;
- estudante procurando experiência;
- empresa com estrutura que não existe;
- template genérico de inteligência artificial.

O foco deve ser apresentar Yago como um profissional que desenvolve soluções digitais para negócios, com transparência sobre seu momento atual e espaço para evolução da marca.

## Princípio comercial

O site não deve existir apenas para demonstrar efeitos visuais ou habilidades técnicas.

A experiência deve conduzir o visitante aproximadamente por:

impacto → entendimento → confiança → prova → redução de objeções → contato.

Design e tecnologia são ferramentas para atingir esse objetivo.

## Projetos e prova de trabalho

Neste momento existem poucos projetos concluídos.

Provavelmente serão apresentados aproximadamente dois projetos reais na primeira versão.

Não inventar:

- clientes;
- projetos;
- depoimentos;
- avaliações;
- resultados;
- números;
- métricas;
- quantidade de clientes;
- experiência profissional.

Poucos projetos bem apresentados são preferíveis a muitas provas sociais artificiais.

Os projetos devem ser tratados como pequenos cases quando houver informações suficientes.

## Estrutura inicial planejada

A arquitetura inicial considerada para a página principal é:

1. Header
2. Hero
3. Proposta / problema
4. Projetos selecionados
5. Serviços
6. Processo
7. Sobre
8. FAQ
9. CTA final
10. Footer

Essa estrutura é uma base de planejamento e poderá ser refinada antes da implementação.

## Conversão

O site deve facilitar ações como:

- entrar em contato;
- solicitar orçamento;
- iniciar conversa pelo WhatsApp quando disponível;
- conhecer projetos;
- entender os serviços.

CTAs devem ser claros e naturais, sem pressão comercial exagerada.

## Copy

Evitar frases genéricas como:

- "Transformamos ideias em experiências digitais."
- "Levamos seu negócio para o próximo nível."
- "Criamos soluções inovadoras."

A comunicação deve ser:

- específica;
- humana;
- natural;
- profissional;
- fácil de entender;
- persuasiva sem exagero.

## Prioridades

Sempre equilibrar:

1. qualidade visual;
2. conversão;
3. performance;
4. organização;
5. acessibilidade;
6. aprendizado e manutenção do projeto.
